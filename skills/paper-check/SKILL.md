# 论文引用检查技能

## 何时使用
用户给出论文文稿（或其中参考文献部分），希望得到：格式问题清单、文献真实性核验、漏引用分析、一份可下载的修改报告。

## 执行步骤
1. 用 `write_todos` 列出计划：解析 → 逐条查格式 → 核验真实性 → 生成报告。
2. 调用 `parse_reference` 解析参考文献条目，并查看返回的 `coverage`（漏引用 / 多余引用）。
3. 对每一条参考文献调用 `check_citation_format`，对照 GB/T 7714-2015 检查格式，记录错误与警告。
4. 对重点或可疑文献（尤其是用户点名、或看起来陌生者）调用 `search_paper_doi` 联网核验；断网时如实告知"无法核验"，不要编造。
5. 汇总上述结果，调用 `generate_report(results=汇总文本, fmt="markdown,excel")` 生成报告与 Excel 表格，写入 /workspace/。
6. 用 3 句话向用户概括：共发现多少格式问题、是否有漏引用、几篇文献核验通过/未通过，并给出报告路径。

## 规范与边界
- 所有结论必须来自工具返回，禁止凭记忆编造文献标题、作者或年份。
- 工具未覆盖的情况标注「待核实」。
- 本技能只检查与核验，不代写、不生成论文正文；涉及学校具体格式以 AGENTS.md 与官方规定为准。
